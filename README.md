# 셐스토리스킵 (prsk-story-macro)

안드로이드 에뮬레이터에서 프로젝트 세카이(일본판)의 이벤트 스토리와 버추얼 라이브를 자동으로 읽고 시청하는 매크로입니다. Windows에서는 LD플레이어 9, 뮤뮤 플레이어, 블루스택 5, 미뮤, 녹스를 쓰고([에뮬레이터](#에뮬레이터) 참고), Apple silicon 맥에서는 BlueStacks Air로 돌아갑니다([맥](#맥-bluestacks-air) 참고).

## 설치

1. [Releases](https://github.com/RilakKuma2/prsk-story-macro/releases/latest)에서 `SekaiStorySkip-win-x64.zip`을 받아 원하는 폴더에 압축을 풉니다.
2. `SekaiStorySkip.exe`를 실행합니다. .NET은 함께 들어 있어 따로 설치하지 않아도 됩니다.
3. 게임을 설치하고 기존 계정으로 로그인한 에뮬레이터를 준비한 뒤, 앱에서 앱플레이어와 인스턴스를 고릅니다.

필요한 것

- Windows 10/11 64비트, [WebView2 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)
- 에뮬레이터 하나 이상: [LD플레이어 9](https://www.ldplayer.net/), [뮤뮤 플레이어](https://www.mumuplayer.com/), [블루스택 5](https://www.bluestacks.com/), [미뮤](https://www.memuplay.com/), [녹스](https://www.bignox.com/). 설치된 앱플레이어와 인스턴스는 자동으로 찾습니다.
- 일본판 프로젝트 세카이와 로그인한 계정, 해상도 **960×540 / DPI 160**

친구초대 매크로와는 별도 앱입니다. 친구초대 매크로를 함께 설치할 필요가 없고, 설정과 기록도 따로 저장합니다.

## 업데이트

Windows에서는 앱을 켤 때마다 이 저장소의 최신 릴리스를 확인하고, 새 버전이 있으면 업데이트할지 묻습니다. 예를 누르면 받아서 덮어쓴 뒤 다시 켜집니다. 상단 **원격 접속** 왼쪽의 **업데이트 확인** 버튼이나 창 위쪽 **업데이트 확인…** 메뉴로 직접 확인할 수도 있습니다.

매크로나 VM 작업 중에는 업데이트하지 않으며, 업데이트를 받는 동안 새 작업도 시작하지 않습니다. 설정이 들어 있는 `local\` 폴더와 진행 기록·스크린샷이 들어 있는 `artifacts\` 폴더는 그대로 남습니다.

맥에서도 **업데이트 확인** 버튼으로 새 버전을 확인하고 DMG를 받을 수 있습니다. 새 DMG를 받아 앱을 교체합니다. 설정과 기록은 앱 밖에 저장되므로 유지됩니다.

## 쓰는 법

1. 제목 옆에서 앱플레이어를 고르고, 미리보기와 이름을 확인해 실행할 인스턴스를 선택합니다.
2. 게임에서 원하는 이벤트 스토리 목록이나 에피소드 목록을 엽니다. 앱에 있는 예시 이미지를 누르면 시작 화면을 크게 볼 수 있습니다.
3. 오른쪽 시작 메뉴에서 필요한 동작을 고릅니다. **중지**를 누르면 선택한 인스턴스의 작업을 멈춥니다.

| 동작 | 하는 일 |
| --- | --- |
| **전체 이벤스** | 스토리 목록 또는 읽던 스토리에서 이어 읽고, 완독하면 다음 이벤트로 이동합니다. |
| **전체 버라** | 미시청 버라 필터를 적용하고 현재 위치부터 순서대로 입장합니다. 카운트다운을 포함해 15초 기다린 뒤 나가고, 참여 완료를 확인해 다음 이벤트로 이동합니다. 잠긴 버라는 건너뜁니다. |
| **겜 재부팅 후 전체 이벤스** | 선택한 인스턴스의 게임만 종료·재실행한 뒤 로그인 → 스토리 목록 → 전체 이벤스 읽기를 진행합니다. |
| **1개 이벤스만** | 현재 에피소드 목록의 이벤트만 읽고, 보상 처리와 완독 확인 후 멈춥니다. Memories처럼 잠긴 다음 화와 SKIP 화가 함께 있는 목록에서도 읽을 수 있는 화부터 시작합니다. |

- 매크로 입력은 선택한 인스턴스 한 개에만 보냅니다. 다른 인스턴스의 미리보기는 따로 표시합니다.
- 스토리는 미읽음/SKIP 필터를 적용해 현재 위치에서 진행합니다. 완료로 판단하기 전에는 목록 맨 위부터 끝까지 다시 검사합니다. SKIP 없이 빨간 느낌표만 있는 화도 읽으며, 과거 완료 기록이 있어도 현재 해금·미읽음 상태를 다시 확인합니다. 완독률은 표시용입니다. 잠긴 화만 남으면 완독으로 기록하지 않고 다음 이벤트로 이동합니다.
- **자동 재개**를 켜면 연결 끊김이나 새 데이터 안내 등으로 중단됐을 때 다시 로그인하고 읽기를 이어갑니다. 복구할 수 없는 상태가 반복되면 멈추고 진행 기록에 남깁니다. 자동 재개가 꺼진 상태에서 오류로 멈추면 오류 아래에 재개 기능 안내를 표시합니다.
- **1개 이벤스만**에서는 튕기거나 오류가 발생하면 자동 재개 설정과 관계없이 중지합니다. 게임을 다시 열고 해당 이벤트의 에피소드 목록에서 직접 시작하세요. RAM 변경은 다음 전체/재부팅 시작으로 미룹니다.
- 상단 언어 버튼에서 한국어·일본어·영어를 고릅니다. 선택은 저장되고 원격 접속 화면에도 적용됩니다.
- **원격 접속**을 켜면 같은 네트워크의 휴대폰이나 다른 PC에서 표시된 주소로 제어할 수 있습니다. 기본 포트는 `8788`이며, 포트와 원격 접속 설정은 이 PC의 로컬 창에서 변경합니다.

기존 계정의 스토리와 버라를 진행하는 앱입니다. 계정 초기화·탈퇴·친구초대·가챠·VM 삭제 기능은 포함하지 않았습니다. 실행 중 계정 삭제·데이터 인계·가챠 등 보호 대상 화면을 감지하면 입력을 멈추고 게임을 다시 실행합니다. **1개 이벤스만**에서는 재실행하지 않고 중지합니다. 대기·중지 상태에서는 게임을 조작하지 않습니다.

## 에뮬레이터

Windows에서는 제목 옆 드롭다운에서 앱플레이어를 고릅니다. 선택한 종류의 인스턴스만 표시하며, 실행 중인 인스턴스가 하나면 자동으로 선택합니다. 여러 개가 켜져 있으면 이름과 미리보기를 보고 고릅니다.

| 에뮬레이터 | 환경 | 인스턴스 생성 |
| --- | --- | --- |
| LD플레이어 9 | Windows | 앱에서 |
| 뮤뮤 플레이어 | Windows | 앱에서 |
| 블루스택 5 | Windows | 블루스택 멀티 인스턴스 매니저에서 |
| 미뮤 | Windows | 앱에서 |
| 녹스 | Windows | 앱에서 |
| BlueStacks Air | macOS / Apple silicon | 블루스택 멀티 인스턴스 매니저에서 |

- 해상도는 **960×540**, DPI는 **160**으로 맞춥니다. 블루스택은 설정 › 고급에서 ADB도 켜 둡니다.
- 상단 **인스턴스 생성**에서 앱플레이어와 이름을 골라 새 VM을 만들 수 있습니다. 새 VM에는 게임 설치와 계정 로그인을 직접 진행합니다. 생성 전 여유 디스크 공간은 **14GB**로 검사하고, RAM은 PC 여유에 맞춰 **3~8GB**로 정합니다.
- 실행에 사용할 RAM은 **3~12GB**에서 선택할 수 있고, 자동 기본 목표는 **8GB**입니다. PC 여유 메모리에 맞춰 적용하며 CPU 수는 유지합니다.
- 블루스택은 여러 인스턴스가 설정 파일을 공유합니다. 다른 블루스택이 켜져 있으면 RAM 변경을 건너뜁니다.
- adb는 앱플레이어에 포함된 것을 사용합니다. 여러 앱플레이어가 동시에 자기 adb를 시작하면 연결이 끊길 수 있으니, 사용할 인스턴스를 먼저 켠 뒤 매크로를 시작하는 편이 좋습니다.

## 맥 (BlueStacks Air)

Apple silicon 맥에서는 BlueStacks Air를 사용합니다.

1. [Releases](https://github.com/RilakKuma2/prsk-story-macro/releases/latest)에서 `SekaiStorySkip-mac-arm64.dmg`를 받아 엽니다.
2. 안의 앱을 **응용 프로그램** 폴더로 끌어 넣습니다. 한국어 시스템에서는 앱 이름이 **셐스토리스킵**으로 표시됩니다.
3. 앱을 열고 BlueStacks Air 인스턴스를 선택합니다. 처음 실행이 차단되면 시스템 설정 › 개인정보 보호 및 보안에서 실행을 허용합니다([Apple 안내](https://support.apple.com/ko-kr/102445)).

필요한 것

- [BlueStacks Air](https://www.bluestacks.com/)와 로그인한 일본판 프로젝트 세카이
- 사용할 인스턴스마다 해상도 **960×540**, DPI **160**, 설정 › 고급의 **ADB 사용**
- adb는 Homebrew나 Android SDK에 있으면 그것을, 없으면 BlueStacks에 들어 있는 것을 사용합니다. 일본어 OCR 도구는 앱에 들어 있습니다.

설정과 기록은 `~/Library/Application Support/SekaiStorySkip`에 남습니다. 앱을 새 버전으로 바꿔도 유지되며, 제어판 로그는 그 안의 `local/panel.log`에서 볼 수 있습니다. 창을 닫거나 Cmd+Q로 종료하면 제어판과 진행 중인 작업도 종료됩니다.

맥의 RAM 기본값과 최대값은 현재 여유 메모리 대신 **전체 메모리**를 기준으로 정합니다. 직접 선택한 값은 해당 최대값 안에서 유지하며, 다음 전체/재부팅 시작 시 적용합니다.

| 맥 전체 RAM | 기본값 | 최대값 |
| --- | --- | --- |
| 8GB 이하 | 3GB | 4GB |
| 8GB 초과~16GB | 6GB | 8GB |
| 16GB 초과 | 8GB | 12GB |

맥판은 자동 업데이트가 없습니다. 새 버전은 DMG를 받아 앱을 교체합니다. 친구초대 매크로와 앱 식별자·제어판 포트·저장 폴더가 분리돼 있습니다.

## 소스에서 빌드

.NET 10 SDK가 필요합니다. 맥 앱을 만들려면 Xcode 명령줄 도구도 필요합니다.

```powershell
.\build-release.ps1   # dist\SekaiStorySkip-win-x64.zip
```

```bash
bash build-release-mac.sh   # dist/SekaiStorySkip-mac-arm64.dmg
```

맥에서 Windows 배포판을 크로스 빌드할 때는 `dotnet publish`에 `-p:SekaiPlatform=windows -p:EnableWindowsTargeting=true -p:ReleasePackage=true -r win-x64 --self-contained true -p:PublishSingleFile=true`를 지정합니다. ZIP 안에는 실행 파일과 `templates/`, 필요한 런타임 파일을 함께 넣습니다.

릴리스는 `SekaiStorySkip.csproj`의 `<Version>`을 올리고 `v<버전>` 태그로 Windows ZIP과 맥 DMG를 첨부합니다. Windows 자동 업데이트는 이 저장소의 최신 공개 릴리스와 `SekaiStorySkip-win-x64.zip`을 사용합니다. 개발용 빌드는 자동으로 교체하지 않습니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `Emulators/` | 앱플레이어 조회·설정·ADB 연결 |
| `StoryReader.cs`, `StoryQueue.cs`, `VirtualLive.cs` | 스토리 읽기·다음 이벤트 이동·버라 시청 |
| `templates/` | 화면 인식에 쓰는 기준 이미지 (960×540) |
| `web/` | 제어판 UI (실행 파일에 포함됨) |
| `mac/` | 맥 앱 창·Vision OCR·아이콘·앱 이름 번역 |
| `local/` | 언어·RAM·원격 접속 등 설정 |
| `artifacts/` | 진행 기록·로그·스크린샷 |
| `tests/fixtures/` | 화면 인식과 동작 검증에 쓰는 캡처 |

이 프로젝트는 개인이 만든 비공식 도구이며, 사용에 따른 책임은 사용자에게 있습니다.

## 릴리스 설명 형식

버그 수정은 패치 버전을 올려 새 릴리스로 배포합니다. 이미 공개한 버전의 태그와 배포 파일은 덮어쓰지 않습니다.

릴리스 설명 맨 위에는 운영체제별 직접 다운로드 링크를 항상 넣습니다. 아래 `<태그>`를 실제 버전 태그로 바꾸고, 해당 릴리스에 첨부한 파일을 연결합니다.

```markdown
윈도우: [**SekaiStorySkip-win-x64.zip**](https://github.com/RilakKuma2/prsk-story-macro/releases/download/<태그>/SekaiStorySkip-win-x64.zip)을 받아 압축을 푼 뒤 실행하세요.

맥: [**SekaiStorySkip-mac-arm64.dmg**](https://github.com/RilakKuma2/prsk-story-macro/releases/download/<태그>/SekaiStorySkip-mac-arm64.dmg)를 받아 앱을 응용 프로그램 폴더로 옮기세요.
```
