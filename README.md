# 셐스토리스킵 (Sekai Story Skip)

안드로이드 앱플레이어에서 **프로젝트 세카이(일본판)** 의 메인·이벤트 스토리와 버추얼 라이브를 자동으로 읽고 시청하는 프로그램입니다.

- **Windows**: LD플레이어 9, 뮤뮤 플레이어, 블루스택 5, 미뮤, 녹스 지원
- **macOS (Apple Silicon)**: BlueStacks Air 지원

![셐스토리스킵 실행 화면](assets/ui-preview.png)

---

## 다운로드 및 설치

👉 [**최신 버전 다운로드 (Releases)**](https://github.com/RilakKuma2/prsk-story-macro/releases/latest)

### Windows
1. 최신 릴리스에서 **`SekaiStorySkip-win-x64.zip`** 을 받아 원하는 폴더에 압축을 풉니다.
2. **`SekaiStorySkip.exe`** 를 실행합니다. (.NET이 포함되어 있어 별도 런타임 설치가 필요 없습니다.)
3. 앱플레이어에 일본판 프로젝트 세카이를 설치하고 로그인한 뒤, 상단에서 앱플레이어와 인스턴스를 선택해 시작합니다.

> **필수 환경**: Windows 10/11 (64비트), [WebView2 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)(Windows 11 기본 포함), 지원 앱플레이어 중 1개 이상 설치

### macOS (Apple Silicon)
1. 최신 릴리스에서 **`SekaiStorySkip-mac-arm64.dmg`** 를 받아 엽니다.
2. **`SekaiStorySkip` (셐스토리스킵)** 앱을 **응용 프로그램(Applications)** 폴더로 끌어다 넣습니다.
3. 앱을 실행하고 **BlueStacks Air** 인스턴스를 선택합니다.
   - 처음 실행할 때 보안 경고가 뜨면 **시스템 설정 › 개인정보 보호 및 보안**에서 실행을 허용해 주세요([Apple 안내](https://support.apple.com/ko-kr/102445)).

> **필수 환경**: Apple Silicon 맥, [BlueStacks Air](https://www.bluestacks.com/mac) 설치 및 설정 › 고급에서 **ADB 연결 사용** 켜기

## 사용 방법

1. 상단에서 **앱플레이어**와 **인스턴스 카드**를 선택합니다.
2. 게임에서 시작할 화면(이벤트 스토리 목록 또는 에피소드 목록)을 띄웁니다. 우측 메뉴의 **예시 이미지**를 클릭하면 어느 화면에서 시작해야 하는지 크게 볼 수 있습니다.
3. 우측에서 원하는 실행 버튼을 누릅니다. 작업을 멈추려면 **중지**를 누릅니다.

| 실행 버튼 | 동작 설명 |
| --- | --- |
| **전체 이벤스** | 미읽음·SKIP 필터를 켜고 현재 스토리 목록(또는 열려 있는 스토리)부터 아래로 내려가며 모든 이벤트·유닛 스토리를 순서대로 완독합니다. |
| **전체 버라** | 미시청 버추얼 라이브 필터를 켜고 순서대로 입장해 15초 대기 후 퇴장합니다. 현재 진행 중인 이벤트(`開催中`)나 잠긴 버라는 자동으로 건너뜁니다. |
| **1개 이벤스만** | 현재 열려 있는 이벤트의 에피소드만 끝까지 읽고 보상 수령 후 멈춥니다. |
| **겜 재부팅 후 전체 이벤스** | 게임을 재실행해 타이틀 로그인부터 스토리 목록 진입까지 자동으로 이동한 뒤 **전체 이벤스**를 시작합니다. |

## 주요 기능

- **1화부터 빈틈없는 순서대로 읽기**
  - `SKIP` 배지가 있는 화와 빨간 느낌표(`!`)만 있는 새 에피소드를 모두 인식하며, 항상 목록 맨 아래(1화)까지 확인한 뒤 순서대로 연속 읽기를 진행합니다.
  - 잠긴 화(🔒)만 남은 스토리는 완독 처리하지 않고 다음 이벤트로 넘어가며, 이후 해금되면 다시 읽을 수 있습니다.
- **해상도·DPI 자동 맞춤 및 재시작**
  - 실행 시 앱플레이어 해상도·DPI가 **960×540 / DPI 160**과 다르면, 화면에 알림을 띄우고 자동으로 앱플레이어 설정을 변경한 뒤 재시작해 스토리를 이어서 진행합니다.
- **자동 재개 (오류·새 데이터 복구)**
  - **자동 재개**를 켜 두면 게임이 튕기거나 날짜 변경(`新しいデータがあります`) 알림이 떠도 자동으로 게임을 다시 켜고 스토리 목록과 필터를 복원해 이어서 읽습니다.
  - 읽기 도중 우상단 메뉴(`…`)가 열려 멈추더라도 20초 뒤 자동으로 닫고 대사를 이어 읽습니다.
- **게임 간편 설치 및 업데이트**
  - 상단의 **게임 설치** / **게임 업데이트** 버튼으로 계정과 다운로드 데이터를 유지한 채 최신 버전으로 업데이트할 수 있습니다.
- **원격 접속 및 다국어 지원**
  - 상단 **원격 접속**을 켜면 같은 Wi-Fi/네트워크에 있는 스마트폰이나 다른 PC에서 진행 상황을 보고 제어할 수 있습니다(기본 포트 `8788`).
  - 한국어, 일본어, 영어 UI를 지원합니다.
- **계정 보호**
  - 기존 계정의 스토리·버라 진행 전용 도구로, 계정 초기화·탈퇴·데이터 인계·가챠 기능은 일절 포함하지 않으며 보호 대상 화면이 감지되면 즉시 입력을 멈춥니다.

## 앱플레이어 지원 및 설정

| 앱플레이어 | 운영체제 | 앱 내 인스턴스 생성 | 해상도·DPI 자동 설정 |
| --- | --- | --- | --- |
| **뮤뮤 플레이어 12** (권장) | Windows | 지원 | 지원 (`960×540 / 160 DPI`) |
| **LD플레이어 9** | Windows | 지원 | 지원 (`960×540 / 160 DPI`) |
| **블루스택 5** | Windows | 멀티 인스턴스 매니저 사용 | 지원 (단독 실행 시 자동 적용) |
| **미뮤 (MEmu)** | Windows | 지원 | 지원 (`960×540 / 160 DPI`) |
| **녹스 (Nox)** | Windows | 지원 | 지원 (`960×540 / 160 DPI`) |
| **BlueStacks Air** | macOS (Apple Silicon) | 멀티 인스턴스 매니저 사용 | 지원 (단독 실행 시 자동 적용) |

- **RAM 설정**: 우측 슬라이더에서 인스턴스에 할당할 RAM(3~12GB)을 조절할 수 있으며, 다음 전체 실행 또는 재부팅 시 반영됩니다.
  - macOS에서는 맥의 전체 메모리에 맞춰 안전 범위가 자동 설정됩니다(8GB 맥: 기본 3GB/최대 4GB · 16GB 맥: 기본 6GB/최대 8GB · 16GB 초과: 기본 8GB/최대 12GB).
- **블루스택 참고**: 블루스택은 설정 파일을 모든 인스턴스가 공유하므로, 다른 블루스택 창이 함께 켜져 있을 때만 수동 설정이 필요하며 단독 실행 중에는 매크로가 자동으로 해상도·DPI·RAM을 변경하고 재시작합니다.

## 업데이트 안내

- **Windows & macOS 공통 자동 업데이트**: 앱을 실행할 때마다 새 버전을 자동으로 확인하며, 상단 **업데이트 확인** 버튼을 눌러 언제든 확인할 수도 있습니다.
- 새 버전이 있으면 변경 내역을 보여주고, **업데이트** 버튼을 누르면 자동으로 최신 버전을 받아 설치한 뒤 앱이 다시 실행됩니다.
- 업데이트를 진행해도 기존 설정과 진행 기록(`local\`, `artifacts\` 또는 `~/Library/Application Support/SekaiStorySkip`)은 그대로 유지됩니다.

## 소스에서 빌드하기

.NET 10 SDK가 필요합니다(macOS 앱 패키징 시 Xcode 명령줄 도구 필요).

```powershell
# Windows 배포 패키지 생성 (dist\SekaiStorySkip-win-x64.zip)
.\build-release.ps1
```

```bash
# macOS 배포 패키지 생성 (dist/SekaiStorySkip-mac-arm64.dmg)
bash build-release-mac.sh
```

> 이 프로젝트는 개인이 제작한 비공식 도구이며, 사용에 따른 책임은 사용자 본인에게 있습니다.
